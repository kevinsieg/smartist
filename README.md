# Salmon & the Laundry Bear Website

Website for the bluegrass and old-time music band from Paris.

Run eg via python: `python3 -m http.server 8000`

## Resources

- **HTML-CSS Layout**: Based on https://codepen.io/bradtraversy/pen/BaoWWjb
- **Video Background**: Best practices from:
  - https://www.gomasuga.com/blog/best-practices-for-html-background-videos
  - https://www.viget.com/articles/best-practices-for-background-videos/
- **Media Queries**: http://stuffandnonsense.co.uk/blog/about/hardboiled_css3_media_queries/

## Video Processing

Video files are processed using ffmpeg. See `scripts/ffmpeg.txt` for processing commands.
